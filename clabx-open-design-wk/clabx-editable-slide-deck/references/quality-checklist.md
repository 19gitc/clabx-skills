# Quality Checklist

Run this before reporting completion.

## PPTX Editability

- [ ] Titles are selectable text, not pixels.
- [ ] Body copy and bullet labels are selectable text.
- [ ] Tables are native cell-like shapes and text boxes.
- [ ] Simple charts are native shapes with editable labels.
- [ ] Diagrams are native shapes and lines.
- [ ] Full-slide images are absent unless explicitly requested.
- [ ] Speaker notes are present when requested.

## Content Quality

- [ ] Every slide has one main idea.
- [ ] Headlines make claims instead of using generic labels.
- [ ] No lorem ipsum, placeholder text, fake names, or invented metrics.
- [ ] All statistics include source or citation notes.
- [ ] Closing slide has a takeaway, decision, or action.

## Visual Quality

- [ ] Text fits inside its boxes at 16:9.
- [ ] No overlapping text, cards, captions, or footers.
- [ ] Accent color is used sparingly.
- [ ] The deck has rhythm: cover, body, section breaks, data, close.
- [ ] Dense slides are balanced by simpler slides.
- [ ] Small text remains readable.

## HTML Preview

- [ ] `preview/index.html` opens locally.
- [ ] Arrow keys navigate slides.
- [ ] `O` opens overview.
- [ ] `S` shows notes when notes exist.
- [ ] Preview content matches `deck-spec.json`.

## Command Evidence

Record the commands run and their result in the final response. If a check was
not possible, say so directly.
