# Editable Layouts

The PPTX must stay editable. Favor simple native objects over visual tricks.

## Editability Rules

- Titles, subtitles, bullets, labels, captions, table cells, and stat values
  are native text boxes.
- Cards, panels, callouts, dividers, and chart bars are native shapes.
- Diagrams are native shapes connected by lines.
- Tables are groups of native rectangles and text boxes, not screenshots.
- Use raster images only for photos, screenshots, textures, or user-provided
  brand assets.
- Never place a full-slide PNG into the PPTX unless the user explicitly asks
  for image-based slides.

## Layout Types

### Cover

Use a large title, small kicker, subtitle, and one accent block or line. Keep
the title editable and avoid flattening it into a background image.

### Section

Use a centered or left-weighted chapter title with a visible section number.
Best after every 4-5 dense slides.

### Bullets

Use for one claim and 3-5 supporting points. Use cards only when labels help
scanning. Otherwise use a clean text column.

### Two Column

Use for before/after, problem/solution, current/future, or option A/B. Keep
column headings parallel in wording.

### Stats

Use 2-4 stat cells. Each cell should have:

- value
- label
- caption or interpretation

Do not show a number without saying why it matters.

### Quote

Use for a real quote, principle, or strong takeaway. Include attribution when
it is a quote from a person or source.

### Timeline

Use for a sequence of 3-6 steps. Each step should have a short label and one
line of explanation.

### Table

Use only when row/column structure is the clearest representation. Keep to 3-5
columns and 3-7 rows. If it is larger, split the table or move detail to an
appendix.

### Image

Use for screenshots, product photos, diagrams supplied by the user, or evidence
that must be seen. Pair the image with editable title, caption, and bullets.

### Closing

Use for one memorable takeaway, decision request, or next action. Do not end
with only "Thank you" or "Questions?"

## Composition Rules

- Use a 16:9 slide: 13.333 x 7.5 inches.
- Keep an outer margin of 0.45-0.65 inches.
- Keep text away from edges and progress dots.
- Prefer left-aligned body text.
- Use one visual hierarchy per slide: title, support, details.
- If a slide needs more than 5 body elements, split it.

## Data Display Rules

- For small bar charts, use native rectangles and labels.
- For simple process diagrams, use native rectangles/circles and lines.
- For complex charts, either simplify them into native shapes or ask whether a
  screenshot is acceptable.
- Cite data in a small native text box.
